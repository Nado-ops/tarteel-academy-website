# Tarteel Academy starter asset pack

These files were extracted from the approved homepage design reference so Codex can match the layout quickly.

## Important limitation

The original clean source photographs and vector artwork were not supplied. Some extracted files may contain parts of the design treatment, shadows, overlays, or nearby elements. They are suitable as temporary build assets and visual references, but the final production site should use the original high-resolution logo, photographs, icons, patterns, and Arabic calligraphy when available.
